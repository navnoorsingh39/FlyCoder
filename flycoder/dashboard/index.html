            About FlyCoder
            
      
            Real neural data
            
      
              
        
            • MaleCNS v1.0 connectome
              • 
        
            • 166,700 neurons · 25,582,938 connections
              • 
        
            • FlyBrain leaky integrate-and-fire simulation
              • 
        
            • Real neuron identities, sensory and descending populations
              • 
        
            • Real simulated spike activity
              • 
      
            
      
            Experimental interface
            
      
              
        
            • Webpage error encoding onto LC10a / LPLC1 / LC4 / LPLC2
              • 
        
            • Action cursor driven by DNa02 laterality
              • 
        
            • Semantic CSS actions, not generated source text
              • 
        
            • Q-assisted selector and idle commit live outside the connectome
              • 
        
            • Reward does not change MaleCNS weights
              • 
      
            
      
            3D embodied visualization
            
      
              
        
            • Original procedural Drosophila built with Three.js primitives
              • 
        
            • The connectome panel is a spatial visualization of real MaleCNS soma positions and sampled real synaptic edges. It does not display complete neuron morphology.
              • 
        
            • Wing taps are an embodied visualization of FlyCoder control channels, not Drosophila motor physiology.
              • 
      
            
      
            
        The 3D fly is an embodied visualization of FlyCoder control signals.
        It is not a biomechanically complete Drosophila locomotion simulation.
        The body animation is an experimental visualization of descending control activity.
        It is not a full musculoskeletal reconstruction of Drosophila biomechanics.
